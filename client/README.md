## 🛠️ Features

- 🍕 **Interactive Menu**: Pizzas, Burgers, Pastas, Sides, Drinks, and Desserts with category filtering and instant search.
- 🛒 **Shopping Cart & Coupons**: Persistent cart with coupon discount code support (`PIZZA20`).
- 💳 **Checkout**: Address collection and multiple payment methods (Cash on Delivery, Cards, UPI).
- 📍 **Real-time Order Tracker**: 5-stage live status stepper synced with backend database.
- 📜 **Customer Order History**: View previous orders and status at `/my-orders`.
- ⚡ **Admin Dashboard**: Revenue KPIs, incoming order management & status updates, menu item CRUD, and user role management.

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start local Vite development server
npm run dev
```

Build for production:
```bash
npm run build
```
