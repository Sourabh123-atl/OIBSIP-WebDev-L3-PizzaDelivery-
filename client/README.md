# 🍕 Pizzario - Full Stack Pizza Delivery Application

Pizzario is a modern full-stack pizza delivery web application built using the MERN stack. It provides a clean and responsive interface where users can browse the menu, register an account, log in securely, manage their cart, and proceed to checkout.

This project was built to demonstrate full-stack web development skills using React, Node.js, Express.js, and MongoDB.

---

## 🚀 Features

### 👤 Authentication
- User Registration
- User Login
- Password Hashing with bcrypt
- JWT Authentication
- MongoDB User Storage

### 🍕 Customer Features
- Beautiful Responsive Homepage
- Pizza Menu
- Shopping Cart
- Checkout Page
- Forgot Password UI
- Responsive Navigation
- Modern UI with Tailwind CSS

### ⚙️ Backend
- REST API using Express.js
- MongoDB Atlas Database
- Mongoose Models
- Authentication APIs
- Environment Variables
- Secure Password Storage

## ⚡ Installation

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Pizzario.git
```

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000

MONGODB_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET_KEY
```
